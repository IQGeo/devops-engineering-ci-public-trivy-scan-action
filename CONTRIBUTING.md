# Contributing to Trivy Image Scanner Action

We welcome contributions to improve the Trivy Image Scanner Action! This document provides guidelines for contributing to this project.

## How to Contribute

### Reporting Issues

If you encounter any bugs or have feature requests, please:

1. Check if a similar issue already exists in the [Issues](https://github.com/IQGeo/devops-engineering-ci-public-trivy-scan-action/issues) section
2. Create a new issue with a clear description of the problem or feature request
3. Include relevant details such as:
   - Steps to reproduce the issue
   - Expected behavior
   - Actual behavior
   - Environment information (OS, Docker version, etc.)

### Submitting Changes

1. Fork the repository
2. Create a new branch for your feature/fix: `git checkout -b feature/your-feature-name`
3. Make your changes following the coding guidelines below
4. Test your changes thoroughly
5. Update documentation if necessary
6. Commit your changes with clear, descriptive messages
7. Push to your fork and submit a pull request

### Coding Guidelines

- Follow existing code style and conventions
- Keep changes minimal and focused
- Ensure all YAML files are properly formatted
- Test your changes with the provided test workflow
- Update the CHANGELOG.md with your changes

### Testing

Before submitting a pull request, please:

1. Run the test workflow locally if possible
2. Verify your changes work with different image types
3. Test different input combinations
4. Ensure backward compatibility

### Documentation

- Update the README.md if you add new features or change behavior
- Add or update examples if applicable
- Update the CHANGELOG.md following the established format

## Code of Conduct

Please be respectful and professional in all interactions. We're committed to providing a welcoming and inclusive environment for all contributors.

## Questions?

If you have questions about contributing, feel free to:
- Open an issue for discussion
- Contact the maintainers

Thank you for contributing to make this action better! 🚀
